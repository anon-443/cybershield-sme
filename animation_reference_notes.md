# Animation Reference Notes

The supplied references demonstrate several interaction families: cursor-reactive surfaces, staggered grid movement, reveal-on-scroll transitions, animated hero treatments, navigation transitions, and hover-led depth cues. For CyberShield, the transferable design principle is **progressive motion that supports hierarchy**, rather than the references’ more disruptive shader, distortion, liquid, or full-page effects.

The planned original motion system will use short transform-and-opacity entrances, a scanning pulse inside the existing radar visual, restrained three-dimensional hover lift for coverage and report cards, and evidence-ledger expansion feedback. It will preserve the pale/emerald product system, avoid copying reference layouts or graphics, and use the existing reduced-motion rule to disable non-essential animation.

For the coverage tooltip request, the references reinforce a hover-led disclosure pattern. CyberShield will use this principle only: each existing coverage card will expose a small, high-contrast metric panel on hover or keyboard focus. It will use a short transform-and-opacity reveal instead of shaders, glass distortion, particle effects, or a copied component treatment, keeping scanning scope clear and the page fast to render.
